Rework loop

state machine 7 nodes · 7 edges

The fix loop is the most-travelled path in the system, and every step of it is adjudicated: QA rejection is recorded as `failed` WITH evidence of the defect, reopening the unit requires a `--reason`, and the stale session id is forced out so re-dispatch always starts a NEW session — a rejected delivery is never silently re-blessed by reusing the one that produced it.

Loop de conserto

máquina de estados 7 nós · 7 arestas

O loop de conserto é o caminho mais percorrido do sistema, e cada passo é adjudicado: a reprovação do QA é registrada como `failed` COM evidência do defeito, reabrir a unidade exige `--reason`, e o id de sessão obsoleto é forçado para fora para que o re-dispatch sempre inicie uma sessão NOVA — uma entrega reprovada nunca é reabençoada em silêncio reusando a que a produziu.
