Ledger state machine

state machine 10 nodes · 13 edges

The journey ledger is the deterministic spine of reliability: a unit's status can only move through transitions the record gate physically accepts — done requires attached evidence AND green CI, reopening finished work requires a reason, and a merged unit is immutable. A drifting coordinator cannot mark work done without proof or clobber finished work.

10CI verdict is five-waydeterministic

The CI gate resolves green | red | pending | none | unknown — never two. pending (still running) is refused, not read as passed; unknown (forge unreachable) abstains rather than guessing green; none requires an explicit, recorded --ci-none to waive. A gate that guesses green is worse than one that abstains loudly.

Máquina de estados do ledger

máquina de estados 10 nós · 13 arestas

O ledger da jornada é a espinha determinística da confiabilidade: o status de uma unidade só se move por transições que o gate de registro aceita fisicamente — concluir exige evidência anexada E CI verde, reabrir trabalho concluído exige um motivo, e uma unidade merged é imutável. Um coordenador à deriva não consegue marcar trabalho como feito sem prova nem sobrescrever o que já terminou.

10veredito de CI é de cinco viasdeterministic

O gate de CI resolve green | red | pending | none | unknown — nunca duas vias. pending (ainda rodando) é recusado, não lido como aprovado; unknown (forge inalcançável) se abstém em vez de chutar verde; none exige um --ci-none explícito e registrado para dispensar. Um gate que chuta verde é pior que um que se abstém em alto e bom som.
